This repo documents my attempt at riding the Saddlesore 1000 - a 1000 mile motorcycle ride in 24 hours.

/index.html contains a publicly available website documenting the ride.

/images contains images of the odometer and gas receipts

/gpx contains GPS files from two devices used to record the ride: a Garmin Tread and a Garmin Montana.
